# 21 · Help and support (`/app/help`)

**Goal:** Reach a human quickly, with the order's context already attached.

## Sections
- **New request:** choose the topic (question about an order, change or cancellation, price or quote question, problem with delivery or goods, account, other), pick the order, describe it, attach photos or files. Context (order, stage, spec version) is attached automatically so the team does not ask for it again.
- **My requests:** list with status (open, waiting for you, resolved), last reply, reference number.
- **Request thread:** messages with the team; replies also appear in Messages.
- **Quick answers:** the most relevant FAQ items for the page the customer came from.
- **Direct contact:** WhatsApp and email `[TBD]`, support hours in Riyadh time `[TBD]`.

## Behaviour
- Price or change requests are never answered by the AI as a price discussion; they create a team request, and the customer is told the team will review it. Nothing is promised.
- Confirmation email with a reference number.
- Anti-spam and file type and size limits.

## Behind the scenes
Each request creates an item in the team console (the queue for every "flag a human" case), with its order context and priority.
